电脑关机后，还能收到消息吗？

本地运行时，电脑需要保持开机、联网且不休眠。部署在长期在线的服务器后，监听由服务器完成，关闭电脑、管理网页或 SSH 隧道都不会停止服务器后台。

服务器部署，需要域名吗？

不需要。通过服务器 IP 建立 SSH 隧道，就可以打开管理界面，无需向公网开放管理端口。当前管理页没有独立账号鉴权，请按文档使用 SSH 隧道访问。

图片和附件也会转发吗？

1.1.0 会转发文字、图片说明和附件提示，并附可用的原消息链接。图片、视频和文件本体暂不上传到飞书，需要回 Telegram 查看。

需要 Telegram 群管理员权限吗？

通常不需要。使用你自己的 Telegram 账号，监听该账号已经加入且可以访问的群组、频道或话题。开启内容保护的消息会被跳过，程序不会绕过访问限制。

飞书接收成功，就一定会弹窗吗？

不一定。“接口已接收”表示飞书接口接收成功，不代表手机必然弹窗。请同时检查飞书群免打扰、手机系统通知权限以及设备网络。

服务器的代理，需要一直开着电脑吗？

不需要，前提是服务器使用自己可访问、独立运行的代理。电脑上的 Sparkle 或系统代理不会自动变成服务器代理。具体配置请查看 README 中的服务器代理说明。
